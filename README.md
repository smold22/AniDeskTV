# AniDesk TV

Клиент [Anixart](https://anixart.com) для Android TV. Навигация с пульта или D-pad,
интерфейс на Compose, воспроизведение через Media3 ExoPlayer.

Это не порт мобильного клиента [AniDesk-Android](https://github.com/smold22/AniDesk-Android)
— отдельный проект того же автора, написанный с нуля под 10-футовый интерфейс.

## Возможности

| Раздел | Что делает |
| --- | --- |
| Поиск | Поиск по названию, список результатов с пагинацией |
| Главная | Продолжить просмотр, «Сейчас смотрят», рекомендации, новинки |
| Расписание | Расписание релизов по дням недели, сегодняшний день открыт по умолчанию |
| Жанры | Каталог по жанрам с пагинацией; список жанров зашит в коде |
| Топ | Чарты: фильтр по типу (сериал/фильм/OVA), сортировка (лучшие, популярные, новые) и направление, пагинация |
| Закладки | Локальный список, разложенный по статусам: история, смотрю, запланировано, просмотрено, отложено, брошено |
| Избранное | Серверный список Anixart, требует входа |
| Страница тайтла | Постер, описание, **связанные релизы**, выбор озвучки, серии, избранное и закладка |
| Плеер | Media3 + Leanback UI: качество, скорость, озвучка, серии, пропуск, панель действий |
| Настройки | Базовый URL API, качество и размер постеров, тема, вход и выход из аккаунта |

Ключевые детали реализации:

- **Связанные релизы** (сиквелы, приквелы) грузятся постранично по
  `/related/{related_id}/{page}`. Конец списка определяется пустой страницей: Anixart
  отдаёт `total_page_count = 0` вместе с непустым `total_count`, поэтому считать
  страницы нельзя.
- **Избранное и закладки** переключаются оптимистично, с откатом при ошибке.
  Закладки живут локально в DataStore и группируются по статусу просмотра.
- **Страница тайтла** открывается на 10-футовом экране: раздел с сериями может
  содержать сотни строк, поэтому связанные релизы вынесены выше, до выбора озвучки,
  а пагинация в них по кнопке, а не по автоподгрузке.
- **Продолжить просмотр** на главной хранит позицию последней серии и выбранную
  озвучку, поэтому кнопка «продолжить» сразу открывает нужный источник.

## Требования

- JDK 21 (Gradle подберёт тулчейн сам, но Android Studio должна быть на 21+)
- Android SDK с `compileSdk = 37`
- Устройство или эмулятор с Android 7.0 (API 24) и выше, поддержка Leanback

Приложение публикуется как TV: `android.software.leanback` обязателен,
сенсорный экран не требуется, ориентация фиксирована landscape.

## Сборка

```bash
./gradlew :app:assembleDebug          # APK для отладки
./gradlew :app:installDebug          # сборка и установка на подключённое устройство
./gradlew :app:assembleRelease       # минифицированный APK (без подписи)
./gradlew :app:lint                  # Android Lint
```

Отладочный вариант ставится рядом с релизным: applicationId получает суффикс
`.debug` (`com.anidesk.tv.debug`), так что оба можно держать на одном устройстве.

Релизная сборка не подписана — signingConfig в `app/build.gradle.kts` не задан,
ключ добавьте сами, если нужен APK для установки.

### Настройка

Версия и идентификатор приложения лежат в `gradle.properties`:

```properties
anidesk.applicationId=com.anidesk.tv
anidesk.versionName=1.2.0
anidesk.versionCode=3
```

Адрес API выбирается в приложении (Настройки → Основной API) из списка
зеркал и хранится в DataStore; по умолчанию используется `api-s.anixsekai.com`.
Полный список — `SettingsStore.API_ENDPOINTS`.

## Архитектура

Мультимодульный Gradle-проект с convention-плагинами в `build-logic`. Все версии
собраны в version catalog `gradle/libs.versions.toml`.

```
app/                 сборка, DI-граф, навигация, плеер
core/
  model/             доменные модели
  mvi/               BaseViewModel<State, Event, Effect>
  navigation/        маршруты и навигаторы
  preferences/       DataStore
  network/           Ktor-клиент, DTO, интерсепторы
  designsystem/      цвета, типографика, TV-компоненты и хелперы фокуса
feature/<name>/
  api/               контракты наружу
  domain/            use case
  data/              репозитории
  presentation/      ViewModel, State, Event, Effect, мапперы
  ui-tv/             Compose-экраны и строки
```

Правила, которые поддерживаются сборкой:

- **core не знает про feature.** Плагин `enforceLayering` роняет сборку, если
  `:core:*` потянет `:feature:*`. Отключается флагом `-PstrictLayering=false`,
  который превращает ошибку в предупреждение.
- **MVI.** Экран наследуется от `BaseViewModel`, держит один `StateFlow` состояния
  и отдаёт одноразовые эффекты через `SharedFlow`. Функции вида `*Action` в плеере
  — обёртки над этими событиями для `GuidedStepFragment` (Leanback-шаги).
- **Изоляция экранов.** Каждая фича — отдельные модули `presentation` и `ui-tv`;
  в `api` лежат интерфейсы вроде `IDetailsNavigator`, которые реализует `app`.
- Экран не ходит в сеть напрямую: `presentation` знает только о `domain`.

### Стек

Kotlin 2.4, AGP 9.4.1, Gradle 9.7, Compose Multiplatform 1.12, Material 3,
Navigation 3 (JetBrains), Hilt 2.60 + KSP, Ktor 3.5 (OkHttp), Coil 3.6,
Media3 1.11, DataStore, core library desugaring.

## Особенности TV

- **core:designsystem** держит всё, что нужно для D-pad: `TvActionButton`,
  `TvTitleCard`, `TvRetryButton`, `RequestFocusUntilTimeout`,
  `TvLazyGridRowFocusNavigation`, восстановление фокуса при пересборке списка
  (`TvLazyFocusRestoreState`), `OfflineBanner` и `GlobalToastOverlay`.
- Плеер — отдельная `PlayerActivity` с Leanback-гайд-фрагментами: качество,
  скорость, озвучка и серии выбираются боковыми панелями, а позиция просмотра,
  выбранные озвучка и источник сохраняются между запусками.

## Известные ограничения

- `RECORD_AUDIO` объявлен в манифесте, но голосовой ввод пока не реализован —
  разрешение можно убрать.
- `usesCleartextTraffic = true` и доверие к сертификатам пользователя: нужно для
  локальных зеркал Anixart, но ослабляет защиту соединения.
- Связанные релизы подгружаются только по кнопке, автоматической подгрузки нет.
- Авторизация — только логин и пароль Anixart; OAuth и восстановление пароля нет.
- Тестов пока почти нет, кроме базового каркаса: JUnit 4 и
  `kotlinx-coroutines-test` подключены, `unit-test` bundle собран, но покрытие
  минимальное.
