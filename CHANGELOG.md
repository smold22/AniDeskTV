## [1.0.0] — 2026-09-27

Первый публичный релиз.

### Добавлено

- **Раздел «Новое» на главном экране** — лента свежих релизов. Эндпоинт `discover/updates`
  отдаёт 404, поэтому лента строится через `filterReleases` с `sort = 0` и `statusId = 2`.
- **Клиентская сортировка Топа по направлению** (по возрастанию / по убыванию).
  Сервер `POST /filter` игнорирует параметр направления (`sort_direction`, `is_desc`, `desc`,
  `order`), поэтому сортировка выполняется на клиенте для каждой загружаемой страницы.
- **Поле `creationDate` в модели `Release`** — используется для сортировки Топа по дате добавления.
- **Единый размер обложек и постеров**, задаваемый в настройках:
  - обложки в Топе, Поиске, Жанрах, Закладках и на Главной используют размер карточки;
  - постер на странице деталей равен размеру карточки Топа;
  - обложка в Расписании — 30% от размера карточки;
  - по умолчанию включён размер `LARGE` (232dp), доступны также 168dp и 200dp;
  - карточки внутри широких ячеек сетки выровнены по центру.

### Исправлено

- **Рейтинг.** Отображался служебный параметр `rating` вместо пользовательской оценки
  `grade` (шкала 0–5). Исправлено во всех экранах: Главная, Поиск, Расписание, Топ,
  Жанры, Закладки и страница деталей. Цвета перестроены под новую шкалу:
  меньше 3 — красный, меньше 4 — янтарный, иначе зелёный.
- **Плеер: автопродолжение после перемотки.** При перемотке шкалой прогресса видео
  оставалось на паузе и требовало повторного нажатия Play. Теперь воспроизведение
  возвращается автоматически, в том числе после кнопок перемотки и пропуска,
  но сохраняется, если паузу поставил сам пользователь.

### Техническое

- **Сборка:** Android Gradle Plugin понижен с 9.4.0 до 9.3.0 — версия 9.4.0 пока
  не поддерживается установленной Android Studio. Gradle 9.7.1, Kotlin 2.4.10,
  Compose Multiplatform 1.12.0, Media3 + Leanback 1.2.0.
- Проект открыт и опубликован: <https://github.com/smold22/AniDeskTV>
  (мультимодульная архитектура: `app`, `core/*`, `feature/*`, `build-logic`).

### Известные ограничения

- Подписи фильтров Топа («Лучшие», «Популярные», «Новые») пока не совпадают
  с порядком сортировки на сервере: `0` — по дате добавления, `1` — по оценке, `2` — по году.
- Лента «Новое» обновляется только при открытии экрана: `discover/updates` недоступен,
  автоматической выдачи свежих релизов пока нет.
